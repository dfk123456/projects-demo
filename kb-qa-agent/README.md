# 基于 LangGraph 的多智能体离线知识库问答系统

> 面向企业内网的私有知识库问答助手：用户上传 PDF/TXT 课件构建专属问答库，全程本地 Ollama 推理、**数据不出内网**。基于 LangGraph 编排 5 个 Agent 状态机，分工明确、边界清晰。

## 功能亮点

- **调度拦截 Agent**：闲聊 / 娱乐 / 生活类问题在第一层直接拦截，不调用任何工具，避免对大模型做无意义调用
- **分类校正 Agent**：区分「大模型技术（tech）」与「深度学习数学（math）」两类问题，携带多轮记忆识别指代，关键词交叉校正防止纯计算题被误判
- **双库 RAG Agent**：技术库与数学库独立持久化存储，章节感知切分避免相邻概念混块，实体一致性过滤保证「问 A 不答 B」
- **充分性判定 + 离线计算**：基于相似度阈值判定本地资料是否充足；卷积尺寸、矩阵运算、概率分布等触发离线公式演算工具，结果不经过大模型推理
- **汇总校验 Agent**：强约束 Prompt 强制模型只能在给定资料范围内作答，幻觉校验后输出，资料不足时如实告知而非编造
- **防幻觉与溯源**：答案强制标注【本地课件】/【计算结果】/【外部补充资料】来源
- **双知识库管理**：PDF/TXT 按 SHA-256 指纹判重实现增量入库；文件头魔数校验拒绝伪装文档

## 技术架构（LangGraph 状态机）

```
用户输入 → [调度拦截] → (闲聊? 直接返回) 
                  ↓ 正常问题
        [分类校正] → tech / math
                  ↓
        [双库 RAG 检索] → 技术库 / 数学库
                  ↓
        [充分性判定] → 不足且前沿? 联网补充 / 纯计算? 离线演算
                  ↓
        [汇总校验] → 强约束作答 + 幻觉校验 → 流式输出
```

## 技术栈

`Python` · `LangGraph` · `Ollama` · `Qwen2.5-7B` · `bge-m3` · `Chroma` · `FastAPI` · `SSE`

## 性能指标

| 指标 | 数值 |
|---|---|
| 单轮响应（GPU 加速后） | 20~50 秒 |
| 单轮响应（优化前） | 100+ 秒 |
| 可用性指标 | 满足离线场景 ≤ 60 秒 |

## 快速开始

```bash
# 1. 准备环境
pip install -r requirements.txt
# 本机启动 Ollama 并拉取模型
ollama pull qwen:7b
ollama pull bge-m3

# 2. 配置
cp config.example.py config.py
# 编辑 config.py 填入你的模型密钥（或设置环境变量）

# 3. 启动
python main_api.py
# 浏览器打开 static/index.html
```

## 目录结构

```

├── agents/          # 各 Agent 实现（调度/分类/双库RAG/汇总）

├── main_api.py      # FastAPI 服务入口

```

## 说明

- 默认 **离线优先**，仅当资料不足且判定为前沿技术时才允许联网补充
- 外部模型可配置不发送课件片段，确保敏感数据不外泄
- 本项目仅用于技术展示，不含任何业务数据
